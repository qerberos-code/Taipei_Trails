# 功能狀態（2026-10-04）

| 原始需求 | 狀態 | 現況 |
| --- | --- | --- |
| 大台北步道資訊 | 部分完成 | 18 條硬編碼示範路線，含公園／河濱跑步；新北登山路線覆蓋少，來源、座標、長度未完整核對 |
| 距離、時間篩選 | 已有初版 | 主清單採原有容許範圍，AI 查詢採嚴格上限 |
| 區域篩選 | AI 已支援 | 可在對話指定區域，主介面未新增行政區選擇器 |
| 新手、熟手、專家個人化 | AI 已支援初版 | sidebar 分級與路線查詢限制；分級為專案草稿，未做個別體能建模 |
| Chatbot | 已實作 | LangChain JS createAgent + OpenAI，支援多輪、路線上下文、錯誤顯示 |
| 右側聊天 sidebar | 已實作 | 桌機右側面板，手機浮動按鈕開啟；可選路線並接著討論 |
| 裝備、水、食物、份量 | 已實作初版 | 工具根據時間、人數與炎熱條件粗估，提供依據與來源 |
| 交通方式 | 部分完成 | 既有交通提示及 Google Maps 多種交通導航，無即時班次／車資 |
| 大台北互動地圖 | 尚未完成 | 尚無地圖、行政區聚合與步道標記 |
| 地圖步道長度與軌跡 | 尚未完成 | 目前只有點座標，沒有 GeoJSON/GPX 路線 |
| 官方資料與路況更新 | 尚未完成 | 沒有同步、版本日期及封閉公告查詢 |
| 即時天氣 | 尚未完成 | AI 不查即時天氣，需使用者提供條件 |
| 繁體中文／英文 i18n | 已實作 | 頂部語言選單、偏好保存、篩選與步道文案、聊天提示／錯誤；後續 AI 回覆依介面語言，既有訊息保留原文 |
| 正式地址／飯店查詢 | 尚未完成 | 原有 Claude 環境查詢不適用一般瀏覽器 |
| 持久化對話、登入 | 尚未完成 | 聊天僅存於頁面記憶體 |
| 線上部署 | 尚未完成 | 目前本機 Node 伺服器；AI 不適用純 GitHub Pages |

優先後續：核對路線資料 → 互動地圖與路線座標 → 即時天氣／交通／路況來源 → 公開部署與用量管理。
